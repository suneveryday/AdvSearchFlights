# Farello v0.10.6

- 更新 React、Tauri、PostHog 和前端构建依赖，刷新 npm / Cargo 锁文件；本次 npm 依赖审计为 0 项已知漏洞。
- 增加 Python 3.12、Node.js 24 版本声明和共享开发环境说明，方便迁移后继续开发。
- 修复历史计划测试受系统日期变化影响的问题，并修正 README 的五个候选目的地说明。
- 新增 GitHub Actions 自动测试、依赖审计、版本一致性检查及 macOS arm64 打包验证。

本版保留现有航班搜索、历史记录、定时搜索和提醒逻辑。

## 下载与安装

下载 `Farello_0.10.6_aarch64.dmg`，打开镜像并将 Farello 拖到 Applications。本版面向 Apple Silicon Mac，沿用 ad-hoc 签名，未进行 Apple 公证。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。安装后的 App 内含 Python 与 fli 后端，无需另外安装开发工具链。
